# Reinable

App description

Reinable is a Vue.js app to manage and track and store information on individual horse profiles.


## Developer information

To serve frontend from backend execute :

    npm run start

app runs on port 3000

## Versions

Version 0.1.0 
All the basic code, frontend and backend functionality

Version 1.0.0
Proper structure for managing multiple profiles.

## The story

I created version 0.1.0 and the initial code based on my first project - teamable. 

I then made this one slightly more complex and quickly realized I need to learn a lot more to implement what I'm trying to implement. 

In 0.1.0 I created a parameterized header component with a more info button - which when clicked could display or hide a profile. 

Then I created a second profile managed to display/hide it with a second added header. I learned a lot in the process but knew this is not the correct structure.

So I created a new git branch to try implement a better structure.
I asked deep seek to help me understand the process and the steps.
