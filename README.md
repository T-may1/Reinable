# Reinable

App description

Reinable is a Vue.js app to manage, track and store information on horse profiles.

Tech stack used:

- Vue.js in Frontend

- Node.js in backend

- MongoDB as database


## Developer information

In development environment run

    export DEV=true

To run application:

    npm run start

Alternatively run "startd" script when developing:

    npm run startd


app runs on port 3000



# Database authentication:

Environment variables:

DB_USER,

DB_PASS,

DEV
