# Reinable

App description

Reinable is a Vue.js app to manage and track and store information on individual horse profiles.
Tech stack used:
Vue.js in Frontend
Node.js in backend
MongoDB as database


## Developer information

In development environment run

    export DEV=true

To run application:

    npm run start

app runs on port 3000


# Database authentication:

Environment variables:

DB_USER
DB_PASS
DEV
